## 📌 Project Overview
This project focuses on analyzing healthcare data including patient history, medical examinations, and hospitalization details to identify patterns in disease risk, treatment trends, and healthcare costs.

The analysis is performed using Microsoft Excel with structured datasets and an interactive dashboard.

---

## 📊 Dataset Components
The project includes multiple structured sheets:
- **Customer Names** – Patient demographic details  
- **Medical Examinations** – Health indicators and test results  
- **Hospitalisation Details** – Admission, treatment, and cost data  
- **Healthcare** – Combined dataset for analysis  
- **Dashboard** – Visual representation of key metrics  
- **Insight Summary** – Derived analytical insights  

---

## 🎯 Objectives
- Analyze disease distribution (especially cancer trends)  
- Identify risk factors such as smoking and BMI  
- Understand hospitalization cost patterns  
- Build an interactive dashboard for decision-making  

---

## 🔍 Key Insights
- Smokers show significantly higher cancer risk compared to non-smokers  
- Increased BMI is strongly associated with higher medical expenses  
- Certain patient groups contribute disproportionately to hospitalization costs  
- Clear patterns observed between lifestyle factors and disease occurrence
